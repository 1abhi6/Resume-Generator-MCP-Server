# 🚀 AI Resume Generator MCP Server

**Generate Ready-to-Send Resumes Instantly**

This project is a **Model Context Protocol (MCP) Server** that automatically creates **ATS-friendly, professional resumes** from any kind of input — raw text, LinkedIn profile, or an existing resume file.  
It delivers high-quality **Word and PDF resumes**, instantly uploaded to AWS with secure download links.

Built by **[Abhishek Gupta](https://linkedin.com/in/iautomates)**, this project blends automation, design, and AI-driven understanding to make resume creation effortless and efficient.

---

## ✨ What It Does

- 💡 Instantly generates complete resumes from text, LinkedIn, or files  
- 🧩 Offers multiple predefined, modern templates to choose from  
- 📄 Produces both Word (.docx) and PDF versions automatically  
- ☁️ Securely uploads files to AWS S3 with short-lived links  
- 🧠 Enhances resumes based on job descriptions  
- 🔒 Provides built-in MCP authentication for safe and private use  
- 🌍 Works remotely — no manual setup needed  

Whether you’re redesigning your existing resume, tailoring it for a job, or starting from scratch, this server ensures a **ready-to-send, beautifully formatted result** within minutes.

---

## 🧰 Powered By

- **FastMCP** for remote model context integration  
- **Python + Pydantic** for structured, reliable data handling  
- **docxtpl + Jinja2** for dynamic resume template rendering  
- **AWS Textract & OpenAI** for intelligent data extraction and understanding  
- **boto3** for seamless AWS uploads  

---

## ⚙️ How It Works (High Level Overview)

1. Choose a predefined resume template  
2. Provide your input (LinkedIn URL, text, or file)  
3. The AI engine extracts, structures, and fills in your details  
4. The MCP Server generates and uploads Word + PDF versions  
5. You instantly receive download links to both  

That’s it — no formatting, no design effort, no wasted time.
